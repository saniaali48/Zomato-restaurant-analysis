This project analyze Zomato restaurant data to understand trends in restaurant types, online ordering , and customer rating.The goal
is to extract that help understand the food delivery and dining marker.
## Tools & Libraries
- Pandas - for data cleaning and manipulation
- Seaborn & Matplotlib - for data visualization
- Juypeter Notebook
## Key Analysis & Insights
** Restaurant type Distribution**: compared counts of dining ,cafes,and buffet resturants
** Online ordering trends **: Analyzed how many resturants offer online vs dine-in only
** Heatmap visualization **: created a heatmap showing count of resturants by type
